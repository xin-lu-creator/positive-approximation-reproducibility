## Description

```text
This record archives the initial-submission reproducibility package for the manuscript “Positive Approximation under Subspace Decoupling: From Frobenius to Spectral Norm.” The package contains deterministic Python verification scripts, fixed theorem-verification constants, exact-rational certificate data, and environment and execution documentation. It verifies the explicit Schatten counterexample constructions and the certified rational 4 x 4 spectral-norm obstruction reported in the manuscript. No external dataset or randomness is required. The scripts support independent checking of the finite-dimensional calculations and do not replace the mathematical proofs in the manuscript.
```
