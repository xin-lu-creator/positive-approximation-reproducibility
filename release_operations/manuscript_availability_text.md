# Manuscript availability text

## Before the Zenodo DOI is known

Do not insert a placeholder DOI into the manuscript.

## After the DOI is generated

Recommended Code availability wording, matched to the SMR structure:

```text
The deterministic Python verification scripts, fixed configurations, exact certificate data, environment specifications, execution scripts, and reproducibility documentation for the submission version are openly available from the GitHub release https://github.com/xin-lu-creator/positive-approximation-reproducibility/releases/tag/v1.0.1-submission and are permanently archived in Zenodo under the version-specific DOI https://doi.org/[VERSION_DOI].
```

Recommended Data availability wording for this theoretical manuscript:

```text
No external empirical dataset is used in this study. The exact certificate table and fixed numerical constants supporting the finite-dimensional verification examples are included in the reproducibility archive identified in the Code availability statement.
```
